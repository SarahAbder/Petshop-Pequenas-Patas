# Petshop

Sistema de atendimento para pet shop desenvolvido em C como atividade acadêmica na UCB. O funcionário faz login, cadastra o cliente e o pet, registra serviços e produtos, e no final o programa emite um comprovante com tudo o que foi feito e o valor total.

## Funcionalidades

- Login do funcionário
- Cadastro de clientes
- Cadastro dos pets
- Registro de serviços (banho, tosa e veterinária)
- Registro de produtos
- Emissão de comprovante com o valor total

## Tecnologias

- Linguagem C

## Objetivo

O projeto tem como objetivo aplicar conceitos de programação em C estudados durante a disciplina na criação de um sistema de atendimento.
